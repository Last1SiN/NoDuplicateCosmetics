# NoDuplicateCosmetics

[English](README.md) | [Русский](README_RU.md)

NoDuplicateCosmetics не даёт уже открытой косметике выпадать снова.

Мод не превращает заблокированную косметику в дополнительное оружие и не подменяет её случайным другим предметом. Уже открытая косметика просто исключается из вариантов до того, как Borderlands 3 выбирает дроп, а остальная часть источника лута продолжает работать как обычно.

## Возможности

- Уже открытая косметика больше не выпадает повторно.
- Фильтрация происходит до финального выбора лута игрой.
- Заблокированная косметика не заменяется посторонними предметами.
- Смешанные пулы с экипировкой и косметикой продолжают работать как обычно.
- Если в отдельной косметической ветке не осталось ничего нового, из неё просто не выпадет косметика.

## Требования

- Borderlands 3
- [BL3 PythonSDK / Oak Mod Manager](https://github.com/bl-sdk/oak-mod-manager/releases/latest)

Для установки и обновления SDK используйте [официальную инструкцию BL3 SDK / Oak](https://bl-sdk.github.io/oak-mod-db/).

## Установка мода

1. Установите или обновите BL3 PythonSDK / Oak по официальной инструкции выше.
2. Скачайте `NoDuplicateCosmetics.sdkmod` из [GitHub Releases](https://github.com/Last1SiN/NoDuplicateCosmetics/releases/latest).
3. При полностью закрытой Borderlands 3 скопируйте `.sdkmod` целиком в `Borderlands 3\sdk_mods\`. Сам `.sdkmod` распаковывать не нужно.
4. Запустите игру, откройте **MODS -> NoDuplicateCosmetics** и включите мод.

Для обновления замените существующий `.sdkmod` новым файлом и перезапустите игру.
